# Host A example assets

Original character created for this project (AI-generated, no third-party art).
Released under the same MIT license as the code, for demo/testing use.

- `sprites/base.png`: full-body still, 941x1672, dark background
- `sprites/m_closed.png`, `m_E.png` (small), `m_A.png` (large): 320x320 face crops, placed at `overlay_offset`
- `sprites/e_half.png`, `e_closed.png`: blink crops (same placement)
- `vo.mp3`: first 8 s of our own TTS voice-over; `vo_timings.json`: per-character TTS timings
